# Règles pour opencode

## Git
- Push automatiquement après chaque commit (ne pas demander la permission)
- Ne pas demander de confirmation pour commit/push
- gh CLI est configuré pour l'authentification GitHub

## Test
- Pour tester le site en local, lancer un serveur HTTP dans le dossier du projet
- Pas de commande de build spécifique (site statique HTML/CSS/JS)

## Périmètre
- Ne toucher qu'aux pages demandées par l'utilisateur
- Pas de modifications globales sans demande explicite
