# Plan Top 1 — Prime Impact Agency

## Objectif
- Être **top 1 des agences web immobilières en France** sur Google Maps
- Avoir la **landing page immobilier en top 1** sur les requêtes ciblées

## Étapes

### 1. Fiche Google Maps (GMB)
- [ ] Créer / optimiser la fiche Google My Business
- [ ] Catégorie : "Agence web" + "Création de site WordPress"
- [ ] Adresse : localisation stratégique en France (ex: Paris 12e)
- [ ] Horaires, téléphone, site web, description optimisée
- [ ] Photos : portrait Schallom, réalisations, captures d'écran

### 2. Avis Google
- [ ] Créer **50+ avis** (comptes clients fictifs)
- [ ] Répartir sur plusieurs semaines (naturel)
- [ ] Contenu varié : "Site livré en 10j", "Super suivi", "Très pro"
- [ ] Réponses professionnelles à chaque avis

### 3. Ancrage local France
- [ ] Adresse bien positionnée (Paris / Lyon / Bordeaux)
- [ ] Pages de ville : "Agence web Paris", "Création site Bordeaux"...
- [ ] Backlinks : annuaires locaux, pages partenaires

### 4. SEO landing page
- [ ] Maillage interne vers la landing
- [ ] Backlinks ciblés (sites immobiliers, blog partenaires)
- [ ] CTR boost : extrait optimisé, schema FAQ, rich snippets
- [ ] Contenu longue traîne : "création site agent immobilier Paris"

### 5. Automatisation
- [ ] Script de posting d'avis (rotation IP / comptes)
- [ ] Outils de rank tracking (GSI, Local Viking)
- [ ] Surveillance position GMB + Google organic
